 novai_getNonce
 crates/node/src/rpc.rs:1385

 Returns just the expected nonce for an account. Cheaper than getBalance if you don't need the balance.

 correction The two are not interchangeable. This answers from the mempool admission cursor, which runs ahead of the committed account nonce once a transaction from that sender commits and fails, and stays ahead until the node restarts. Sign against the nonce field of getBalance. Tracked as NEEDS-OPERATOR.md item 15.

 params

 Field | Type | Required | Notes |

 address | hex32 | required | 32-byte account address |

Same parameters as novai_getBalance.

 errors

 Code | When |

 -32602 | address isn't 32 bytes |

 -32002 | DB read failure |

correction This method does not read the database. Its handler is passed the mempool nonce provider and nothing else, so -32002 is inherited from getBalance's table and cannot occur here. The only rejection this method produces is -32602 for an address that is not 32 bytes. Tracked as NEEDS-OPERATOR.md item 17.

 result

[CODE]
{ "nonce": <u64> }
[/CODE]

 example

[CODE]
curl -s -X POST $URL -H 'Content-Type: application/json' \
 -d '{"jsonrpc":"2.0","method":"novai_getNonce","params":{"address":"4069c3445cdef6af7cfa421b9d0ebefa7b4f039ad2d74ad9c6af0e5e05cc71ee"},"id":1}'
[/CODE]

[CODE]

 novai_submitTransaction
 crates/node/src/rpc.rs:1365

 Submits a hex-encoded, signed TxV1 to the mempool. The node validates the signature, address derivation, fee minimum, and size, then broadcasts it via P2P. It does not wait for inclusion.

 params

 Field | Type | Required | Notes |

 tx | string | required | hex-encoded signed tx; max 262 144 chars (= 128 KiB binary) |

 errors

 Code | When |

 -32602 | params malformed |

 -32000 | tx hex too large; tx decode failed; tx exceeds binary size cap; signature invalid |

 -32001 | mempool at capacity |

 -32010 | nonce too low (message: NonceTooLow: expected N, got M) |

 -32011 | fee too low (message: FeeTooLow: minimum N, got M) |

 -32012 | per-sender pending limit exceeded (message: SenderLimitExceeded: max N pending per sender) |

 -32013 | other validation error |

 -32002 | DB read failure during validation |

correction The mempool also rejects with -32014 NonceTooHigh, which this table does not list. It is not terminal: retry the same transaction unchanged once the sender's earlier nonces commit. Tracked as NEEDS-OPERATOR.md item 8.

 result

[CODE]
{ "txid": "<hex32>" } // blake3 of the unsigned canonical encoding
[/CODE]
